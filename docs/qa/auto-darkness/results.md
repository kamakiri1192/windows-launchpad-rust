## 5. Conclusions

- Mean dilution (half_split_white_dark, golden medium): Current -> d=0.000 (none), CoverageTuned -> d=0.041 (weak), ContrastPerceptual -> d=0.160 (strong). The percentile strategy resolves the 50/50 dilution (p90 sees the bright half); the coverage strategies still average it away.
- Small bright window (small_white_window, golden weak): Current -> d=0.000 (none), CoverageTuned -> d=0.000 (none), ContrastPerceptual -> d=0.000 (none). Coverage-based strategies dilute the ~15% white patch to zero; the percentile is all-or-nothing (it saturates to strong whenever the quantile rank lands inside the patch), so "weak" is unreachable for this case with either family.
- Saturated bright colors (bright_saturated_yellow, golden medium): Current -> d=0.000 (none), CoverageTuned -> d=0.000 (none), ContrastPerceptual -> d=0.160 (strong). The white-score chroma gate zeroes every saturated pixel, so coverage strategies are blind to this case; the percentile over-responds (strong) because saturated yellow is bright in luminance.
- Saturated dark colors (bright_saturated_blue, golden medium): all strategies -> d=0.000/0.000/0.000 (none). Perceptual luminance says the image is dark, so no darkness is warranted; the golden "medium" for this case is likely wrong.
